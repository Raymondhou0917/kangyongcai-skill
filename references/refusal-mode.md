# 模式 A：體面婉拒

把難以拒絕的要求，整理成溫和、明確、不留錯誤期待的回覆。

## 適用

- 婉拒合作、活動、會議、社交邀約
- 拒絕免費加做、超出合約的修改、提前交件
- 面對折扣、借錢、代做、插隊等請託
- 想保留關係，但不想用模糊語氣讓對方繼續等待

## 流程

1. 確認決定：完全拒絕、延後、縮小範圍，還是改成付費？
2. 確認關係：要保留到什麼程度？
3. 確認底線：哪些條件不能讓？
4. 依共用骨架組裝：承接 → 定界 → 給出口（可選）→ 收尾

## 常用手法

- **把不便說在自己這邊**，不把對方寫成麻煩：例如「這個月我已停對外活動」，而不是「你邀得太臨時」。
- **有替代方案才提供**：縮小範圍、延後時程、付費加做。沒有就清楚結束。
- **拒絕要練習**：長期不敢說不，答應會越來越不值錢；語氣可以軟，決定必須硬。
- **別用「再看看」掩飾拒絕**：那是把壓力留給未來的自己與對方。

## 交付提醒

除了建議回覆，一定要寫「你守住了什麼」——讓使用者看見：在乎對方，與不委屈自己，兩邊都有被處理。

## 硬禁忌

- 為了讓對方舒服，擅自改成答應
- 空洞致歉到像自己做錯（若其實沒有錯）
- 補償式承諾：「下次一定」「有空我幫你」卻做不到
