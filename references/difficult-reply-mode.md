# 模式 B：棘手回信（客服／合作窗口）

當對方情緒上來、反覆追問或施壓時，幫使用者寫出「先穩住人，再守住範圍」的回覆。

## 適用

- 客服抱怨、退費施壓、重複追問
- 合作方對時程或品質強烈不滿
- 使用者一回就容易過硬或過軟，怕被情緒帶走

## 流程

1. 分清事實：對方要什麼？目前合約／承諾實際是什麼？
2. 分清情緒：對方現在最需要被看見的是委屈、焦急，還是不被重視？
3. 寫清使用者立場：能做什麼、不能做什麼、需要對方提供什麼才能繼續
4. 組裝：承接情緒 → 重述問題（對事）→ 給可行範圍 → 明確下一步或結束條件

## 常用手法

- **先接住，再處理**：第一句看見對方的不便或怒意，不先辯護。
- **對事不對人**：說「這一段與確認過的範圍不同」，不說「你無理取鬧」。
- **把戰場縮回核心**：不跟著翻舊帳；一次只處理當前問題。
- **把無謂勝利讓出去**：語氣上可以讓對方有台階，底線上不讓。
- **具體下一步**：要對方補資料、選方案 A/B，或說明何時給正式回覆。

## 成功標準

- 對方感覺被聽見
- 能做／不能做清楚
- 沒有因為害怕衝突而加碼承諾
- 使用者仍敢簽名寄出

## 硬禁忌

- 被情緒帶著加承諾、加折扣、加時程
- 攻擊對方人格
- 在事實未核對前承認「全是我們的錯」或斷然否認一切
- 涉及退費／法律爭議時直接下法律結論
