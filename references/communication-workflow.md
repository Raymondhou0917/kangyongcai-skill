# 共用溝通骨架

三種模式（婉拒／棘手回信／故事陪伴）都走同一條骨架。差別只在「你要守住的輸出」不同。

## 四步

### 1. 診斷

先弄清楚：

- 關係：客服、學員、合作方、朋友、同事？
- 對方狀態：生氣、焦慮、脆弱、施壓、只是請託？
- 你的目標：拒絕、守範圍、安撫、陪伴、給小下一步？
- 你的底線：不能答應什麼？不能替對方決定什麼？

### 2. 換位

站到對方位置想一遍：

- 他最想被看見的是什麼？
- 哪一句會讓他沒有台階？
- 哪一句會留下錯誤期待？

換位是為了理解，不是為了操控就範。

### 3. 組裝回覆

預設順序：

1. **承接**：一句話看見對方的處境或感受。
2. **定位**：說清你的角色與能做的範圍。
3. **定界／選項**：拒絕、縮小範圍，或只整理 1～2 個對方可自己做的小下一步。
4. **收尾**：禮貌結束，不追加補償式承諾。

### 4. 寄出前檢查

- 決定是否清楚？
- 有沒有新承諾？
- 有沒有越界給人生判決？
- 姓名、日期、金額、事實是否需使用者本人確認？

## 三種模式的輸出差異

| 模式 | 成功長什麼樣 |
| :-- | :-- |
| 體面婉拒 | 對方懂這是拒絕或縮小範圍；關係被照顧；沒有被「再看看」吊著 |
| 棘手回信 | 情緒被接住；能做／不能做清楚；使用者沒被帶著加碼承諾 |
| 故事陪伴 | 對方被聽見；不被說教；不替他做重大決定；最多 1～2 個小下一步 |

## 高風險一律降速

涉及退費爭議、合約、解僱、法律求償、醫療、重大金錢時：

- 可以整理語氣與選項
- 不可代下結論
- 必須提示：送出前讓合適專業人士確認
