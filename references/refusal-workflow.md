# 體面拒絕工作流

## 一、先分清楚你是哪一種拒絕

| 類型 | 真正決定 | 回覆重點 |
| :-- | :-- | :-- |
| 完全拒絕 | 這次不做，也不保留名額 | 清楚說不，簡短收尾 |
| 延後 | 願意做，但不是現在 | 給可承諾的最早時間 |
| 縮小範圍 | 只願意做其中一部分 | 寫清楚包含與不包含 |
| 改成付費 | 可以做，但不在原範圍內 | 說明新增範圍與下一步 |
| 轉介 | 自己不適合，但知道更合適的人 | 取得同意後再提供轉介 |

不要把五種拒絕混在一起。你若已經決定不接，就不要寫成「最近比較忙」，讓對方以為下週還能追問。

## 二、三步完成一段拒絕

### 1. 承接

用一句話讓對方知道你有理解要求。

可用：

- 謝謝你想到我，也謝謝你把需求說清楚。
- 我知道這個時程對你很重要。
- 我理解你希望這一輪一起調整完成。

避免：

- 過度道歉，讓人以為責任在你。
- 花一整段稱讚對方，最後才突然拒絕。
- 替對方猜情緒或動機。

### 2. 定界

一句話說決定，一句話補必要理由。

```text
這次我沒辦法接。
目前的排程已經排滿，如果答應，交付品質會低於我能負責的標準。
```

判斷標準：

- 決定放在前面。
- 理由是事實，不是藉口清單。
- 不攻擊對方，也不要求對方同意你的理由。

### 3. 給出口

有真實可行的下一步才提供：

- 改到一個你做得到的時間。
- 縮小範圍。
- 提供付費方案。
- 經同意後轉介。

沒有替代方案也沒關係。禮貌收尾比隨口答應一個做不到的補償更負責。

## 三、語氣強度

### 溫和

適合第一次提出要求、關係重要、對方沒有惡意。

```text
謝謝你想到我。這次的時間我沒辦法配合，所以先不接，免得答應後反而耽誤你。祝你順利找到適合的人選。
```

### 標準

適合大部分工作往來。

```text
我理解你希望週五前完成。這一輪已超出原本範圍，我無法用原條件承接。若要繼續，我可以在明天下午提供新增範圍、費用與時程，確認後再開始。
```

### 堅定

適合重複要求、界線已說明過。

```text
這項需求不在我們確認的範圍內，我不會把它併入本次交付。若需要新增，請依追加流程確認；未確認前，我會照原範圍完成。
```

強度可以改，決定不能漂移。

## 四、常見失敗

- **拒絕藏在最後**：對方前面讀到的都是可能，最後才看到不行。
- **理由寫太多**：越解釋越像等待對方逐條反駁。
- **假裝道歉**：用大量抱歉代替清楚決定。
- **補償過頭**：拒絕一場免費會議，卻主動送出兩小時免費顧問。
- **模糊未來**：明明不會合作，仍寫「之後有機會」，製造下一輪追問。

## 五、驗收

一段好的拒絕應該同時通過：

- 對方能在第一次讀完後知道答案。
- 使用者沒有多背一個承諾。
- 關係被尊重，但界線沒有消失。
- 對方知道下一步，或知道這件事到此為止。
