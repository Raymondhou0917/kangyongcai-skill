## 這個 skill 是怎麼長出來的

> 好的溝通 skill，不該只是「用溫柔語氣說話」。  
> 它要回答的是：當你真的卡住時，下一步怎麼組出一封敢寄出的信。

```
你      ❯ 我想做一個「像蔡康永那樣會說話」的 AI。
            是不是把他的金句丟進去就好？

研究     ❯ 那通常會變成 cosplay。

            更有用的做法是：從公開訪談、媒體訪問，
            以及《奇葩說》裡反覆出現的溝通分寸出發，
            問三個問題——

            1. 他反覆在解決什麼難題？
            2. 哪些觀察能變成一般人可執行的步驟？
            3. 拿掉姓名之後，工作流還有沒有用？

            過得了第三題的，才進這個 skill。
```

故事分三步：

**第一步 — 先定用途，不要先追口吻。**  
不是做「蔡康永聊天機器人」，而是做「難開口、難回、難拒絕」的回信引擎。用途定了，才不會變成名言集。

**第二步 — 把公開觀點壓成可執行規則。**  
從公開訪談與節目討論裡，抽出反覆出現的分寸：先接住人、把別人放在心上但不討好、決定要說清楚、替代方案必須做得到。

**第三步 — 做成三種工作流，而不是一種語氣。**  
同一套骨架，分出婉拒、棘手客服、故事陪伴三種模式。AI 先判斷情境，再產出可寄出的草稿。

> 一句話總結：這個 skill 不是「假裝某人開口」，  
> 是「把公開可見的溝通智慧，做成你今晚就能用的回信系統」。

## 效果示例

### 問：客戶要我免費大改一版，週五前交，怎麼拒？

```
溝通顧問 ❯ 先接住他的焦急，再守住範圍。

            建議回覆：

            「我知道週五的檔期對你很重要，也理解現在很趕。
            我把前面確認的範圍對了一次：這次的新方向
            已經超出原本兩輪修改，因此無法直接併入原費用。

            如果要繼續，我可以明天下午前提供新增範圍、
            費用與可交付日期。確認後再開始。」

            你守住了什麼：沒有因為害怕衝突，答應免費重做。
```

### 問：學員來信說想離職又怕家人反對，我不知道怎麼回

```
溝通顧問 ❯ 這封信要的是陪伴，不是人生判決。

            建議回覆：

            「謝謝你把這些寫下來。光是把『家人要穩定』
            和『自己怕來不及』同時說清楚，就已經很不容易了。

            我無法替你決定要不要離職。我比較想陪你看的是：
            這兩週讓你最喘的，是對現況的不滿，還是對未知的害怕？

            如果願意，你只要回我其中一件：
            最想改善的現況是哪一件；
            或在不做離職決定的前提下，兩週內最小一步是什麼。」

            你守住了什麼：有溫度，但不替對方做重大決定。
```

### 問：這跟 ChatGPT 套個「高情商」面具有什麼不同？

```
溝通顧問 ❯ 差在「有沒有工作流」。

            一般 persona prompt 是：
            「請用溫柔高情商的語氣回覆。」
            那常常會變成雞湯，或偷偷幫你加承諾。

            這個 skill 不一樣：

            1. 先問關係、目標、底線，再寫信
            2. 三種情境各有成功標準與硬禁忌
            3. 每次交付都要標出「你守住了什麼」
            4. 不冒充本人，不靠口頭禪堆人物感

            所以差別是：面具是裝扮；
            這個 skill 是把溝通分寸裝進可檢查的系統。
```

## 蒸餾了什麼

### 三種工作流

| 模式 | 你卡住的時候 | 成功長什麼樣 |
| :--- | :--- | :--- |
| **A 體面婉拒** | 想說不，又怕傷人 | 決定清楚，沒被「再看看」吊著 |
| **B 棘手回信** | 客服／合作方情緒上來 | 先接住，再守能做／不能做 |
| **C 故事陪伴** | 對方很脆弱，你怕講空話 | 被聽見，不替人做人生判決 |

### 8 個心智模型

1. 舒服地做自己，才是情商的起點  
2. 把對方放在心上，但不是為了討好  
3. 先接住情緒，再處理事情  
4. 明白、剛剛好、慢慢來  
5. 問怎麼辦，別只問為什麼  
6. 你說出口的話，會反過來塑造期待  
7. 把無謂的勝利讓給對方  
8. 聰明地分配心力  

### 表達 DNA（風格化，非口吻扮演）

| 特徵 | 做法 |
| :--- | :--- |
| 短句好讀 | 一行一個呼吸，先立場後理由 |
| 先承接 | 第一句看見對方處境 |
| 分寸清楚 | 核心決定硬，邊緣語氣可柔 |
| 留台階 | 對事不對人，不把對方寫死 |
| 反模式 | 雞湯、假開放、口頭禪 cosplay |
